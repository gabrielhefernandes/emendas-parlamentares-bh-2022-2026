## Procedimento para publicação

Os documentos devem ser copiados para **esta mesma pasta** com seus nomes originais, sem alteração de conteúdo, páginas ou compressão. Para os quatro arquivos, inclusive o de 2025 (cerca de 56 MB), recomenda-se usar **GitHub Desktop** ou `git push` em vez do upload pelo navegador do GitHub (que limita uploads individuais a 25 MB).

Depois da publicação, confirmar os quatro arquivos e comparar seus SHA-256 com os valores acima. Uma vez confirmados, atualizar esta nota para indicar que os documentos estão disponíveis.

Os documentos são referências de planejamento e orientação para a indicação de emendas, **não comprovantes de que uma proposta listada foi efetivamente executada**. A autoria é da Prefeitura de Belo Horizonte e dos órgãos municipais responsáveis pela elaboração.
