# Pipeline R

1. `01_importacao_padronizacao`: obtenção e normalização de bases;
2. `02_codificacao`: incorporação de categorias e critérios;
3. `03_localidades`: chaves e relações territoriais;
4. `04_georreferenciamento`: geocodificação e precisão;
5. `05_mapas_emendas`: cartografia orçamentária;
6. `06_mapas_eleitorais`: seções eleitorais e mapas;
7. `07_analises`: estatística e visualizações.
