# emendas-parlamentares-bh-2022-2026
Replicabilidade e transparência da monografia em ciências sociais que analisa as emendas parlamentares individuais dos vereadores de Belo Horizonte para o período de 2022-2026, codificando tematicamente cada uma das emendas manualmente e cadastrando uma localidade quando o objeto da emenda fornecido pelo vereador possibilita georreferenciação
