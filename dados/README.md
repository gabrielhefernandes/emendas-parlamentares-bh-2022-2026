# Dados

- `brutos/`: arquivos de origem preservados sem alteração;
- `codificados/`: emendas classificadas por exercício;
- `localidades/`: relações entre emendas e espaços físicos;
- `partidos/`: partidos e medidas ideológicas;
- `eleitorais/`: votos por seção e correspondência territorial.

As pastas poderão estar vazias de bases até os arquivos binários serem publicados.
