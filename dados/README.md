# Dados

- `brutos/`: arquivos de origem preservados sem alteração para cada ano;
- `codificados/`: emendas classificadas tematicamente para cada ano de forma manual via codebook;
- `eleitorais/`: votos por seção e correspondência territorial.
- `localidades/`: base de dados geral das localidades e relações entre emendas e espaços físicos;
- `partidos/`: base geral de partidos e medidas ideológicas;
