# Localidades

Cada planilha anual reune as abas `LOCALIDADES_APRESENTACAO`, em que se faz uma apresentação das localidades e seus respectivos IDs_emendas; `LOCALIDADES_MESTRE`, em que se mostra as localidades e seus respectivos IDs_localidades e `RELACOES`, em que se mostra a relação emenda-localidade de forma individualizada.

As bases são longitudinais, ou seja, os IDs_localidades são acumulados ao longo dos anos. Por exemplo: há uma localidade em 2022 cadastrada com ID_localidade LOC_12. Essa localidade se repete para uma emenda em 2023. Nesse caso, o ID LOC_12 será atribuído. 
Caso a localidade seja nova, um novo ID_localidade será concedido.
