# Localidades — 2025

Arquivo preparado para esta pasta: `localidades_2025_3_abas.xlsx`, contendo `LOCALIDADES_APRESENTACAO`, `LOCALIDADES_MESTRE` e `RELACOES` extraídas da planilha codificada de 2025.

**Situação:** aguarda transferência para o GitHub. Nas exportações preparadas, os valores das três abas foram comparados com o arquivo codificado de origem. Os identificadores de localidades seguem referência longitudinal: a mesma localidade física deve conservar seu ID entre anos, respeitando decisões sobre endereços efetivamente distintos.
