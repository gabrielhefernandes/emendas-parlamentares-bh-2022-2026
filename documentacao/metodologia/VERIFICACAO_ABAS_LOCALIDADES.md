# Verificação das abas de localidades

Na preparação do pacote local, foram criadas cinco planilhas contendo as três abas territoriais de cada ano, totalizando 15 abas. Os valores das células foram comparados com os originais das respectivas planilhas codificadas, sem diferenças detectadas. **Essa verificação de valores não implica identidade byte a byte dos XLSX derivados**, que têm estrutura de arquivo diferente. Os XLSX codificados originais foram copiados sem alteração binária.
