# Metodologia

A codificação temática utiliza o [manual CAP/Brasil (2019)](https://comparativeagendas.s3.amazonaws.com/codebookfiles/CodeManual_Junho_2019_4.pdf), com política substantiva, um macrocódigo e um subcódigo. O estudo acrescenta dimensões próprias: saúde orçamentária, público-alvo, georreferenciabilidade, credor, endereços e localidades.

**Regra territorial conservadora:** GEO=1 exige vínculo suficientemente explícito entre a destinação e uma localidade física; sede administrativa ou endereço cadastral isolado não basta. Unidades assistenciais com uso indissociável do imóvel e casos hospitalares requerem avaliação contextual, especialmente a exceção provisória de 2025.

O PDF de critérios 2023 já preparado é um documento histórico de trabalho; decisões finais e logs das bases consolidadas prevalecem quando formalmente documentados. Arquivo PDF aguardando transferência para o GitHub.
