# Mapas das emendas — 2025

Este diretório reúne diretamente os mapas das destinações orçamentárias classificadas como `georreferenciavel = 1` para 2025, sem subdivisão por saúde.

Em cada mapa, informar a seleção de dados utilizada, a fonte da geometria, o sistema de coordenadas, a data dos dados, a versão da base de emendas e o tratamento de proxies de ruas, trechos e praças.

**Os mapas finais ainda não foram enviados para publicação.**
